# 🚁 KevinD RC RPM Calculator

### Calculate. Configure. Fine-Tune. Fly.

The **KevinD RC RPM Calculator** is a free, web-based tool designed for electric and nitro RC helicopter pilots who want an easy way to calculate head speed, explore drivetrain gearing, and fine-tune their helicopter setups.

From choosing the right motor and pinion combination to calculating nitro engine RPM and managing custom helicopter models, the KevinD RC RPM Calculator brings essential setup tools together in one convenient application.

## Key Features

### ⚡ Electric Helicopter Calculator
- Calculate estimated main rotor head speed.
- Adjustable motor KV, battery cell count, voltage, efficiency, and throttle.
- Support for 2S through 16S battery configurations.
- Explore gearing combinations and estimated RPM changes.
- Visual RPM feedback and adjustable controls.

### 🚁 Nitro Helicopter Calculator
- Dedicated Nitro mode with engine RPM calculations.
- Support for 2-, 3-, and 4-gear transmissions.
- Interactive drivetrain diagrams.
- Calculate head speed using estimated or measured engine RPM.
- Custom gearing configurations for nitro helicopters.

### ⚙️ Helicopter Model Database
- A growing catalogue of popular RC helicopter manufacturers and models.
- Select verified gearing configurations.
- Support for manual gearing adjustments and custom models.
- Direct-drive support.
- Model verification records with source information.

### 📋 Advanced Model Management
- Identify models with unverified gearing.
- Manually enter and review drivetrain specifications.
- Manage personal gearing configurations.
- Prepare verified catalogue updates for publication through GitHub.
- Export and import model data for backup and transfer.

### 📚 Interactive Tutorial
- Built-in guided walkthrough for new users.
- Dedicated instructions for electric and nitro setups.
- Explanations of battery voltage, gear ratios, efficiency, and RPM calculations.
- Rerun the tutorial whenever needed.

### 📱 Installable Web Application
- Works on modern desktop and mobile browsers.
- Installable Progressive Web App (PWA).
- Offline functionality using locally cached application files.
- No subscription or app store installation required.
