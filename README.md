# KevinD RC RPM Calculator

An installable RC helicopter head speed and gearing calculator for electric and nitro setups.

**[Open the calculator](https://harrykd33.github.io/KDRC-RPM-Calculator/)**

## Getting started

1. Open the calculator using the link above.
2. Select **E** for Electric or **N** for Nitro.
3. Choose a verified model or enter your own gearing with **Saved Models**, then adjust the power and throttle settings to estimate head speed.
4. Use **Tutorial** for a guided explanation of the controls.

Confirm that the gearing matches your installed drivetrain. Calculated head speed is an estimate.

## Install and use offline

Use your browser's install or Add to Home Screen option to keep the calculator on your device. After the initial online visit, the app caches its files for offline use.

## Personal gearing library

Open **Manage Models** to save personal gearing on your device. Custom entries are stored in your browser and do not sync automatically between devices. Export a JSON backup before clearing browser data or moving to another device, then import it to restore your models.

## Hosting and verified models

Host the application files together on an HTTPS site, keeping their relative paths unchanged. See [PUBLISHING.md](PUBLISHING.md) for deployment instructions and the process for publishing verified gearing.
